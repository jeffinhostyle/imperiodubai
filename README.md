# Império Dubai Squad - Gerenciador de Arbitragens

Sistema completo para gerenciamento de arbitragens esportivas, Wingo e Roleta.

## Funcionalidades

- Dashboard com gráficos de desempenho
- Cadastro de arbitragens por categoria
- Cálculo automático de retornos
- Relatórios personalizados
- Autenticação com Google
- Armazenamento seguro na nuvem

## Como Usar

1. Faça login com sua conta Google
2. Cadastre suas arbitragens nas respectivas categorias
3. Acompanhe seus lucros e movimentação financeira
4. Gere relatórios por período

## Tecnologias Utilizadas

- HTML5, CSS3, JavaScript
- Firebase Authentication
- Firebase Firestore
- Chart.js
- Font Awesome
